# Multi-Agent AI Engineering Assistant

## Overview

A Python-based multi-agent AI system designed to assist developers with software engineering tasks through coordinated intelligent agents.

## Project Objectives

- Analyse software requirements.
- Plan software development tasks.
- Research technical solutions.
- Design software architecture.
- Generate and review code.
- Test and validate generated solutions.

## Technology Stack

- Python
- Git and GitHub

## Project Structure

- agents: AI agent modules
- tools: Utility functions
- memory: Memory management
- tests: Automated testing
- config: Configuration settings
